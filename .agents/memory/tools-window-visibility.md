---
name: Music and Brain Freeze utility window
description: Visibility and walkthrough rules for the shared Music and Brain Freeze controls.
---

The shared Music and Brain Freeze utility window is minimized for new users, with a compact Tools control to the right of the independently centered ColdStreak logo. Its expanded state may be remembered after the user chooses it. The Brain Freeze icon is a compact inline launch control and can manually start a trivia session without changing the automatic in-plunge preference.

**Why:** Music should not compete with the plunge timer, while Brain Freeze must remain discoverable even when its opt-in preference is off.

**How to apply:** Keep the Brain Freeze icon visible in the expanded utility window regardless of preference; its tap launches the game directly, while the preference still controls automatic in-plunge trivia. The first-open walkthrough should open the window while introducing both tools, then restore the minimized default when the tour ends.
