---
name: Streak Freeze visibility
description: Product preference for when the Streak Freeze control should appear.
---

Streak Freeze should not be a permanent button or tile on the Home screen. It should appear contextually when the user has missed exactly yesterday and can use a freeze to repair the streak.

**Why:** A persistent Freeze control made the main screen feel like the feature was always active, even when there was no missed day to repair.

**How to apply:** Keep the automatic missed-day prompt and modal flow. Do not re-add always-visible Home entry points unless the product owner explicitly changes this preference.
