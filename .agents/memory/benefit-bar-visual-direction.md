---
name: Benefit Bar visual direction
description: Approved compact visual treatment for the Benefit Bar goal selector and selected rail.
---

Use the Clean Rails layout with a small inline outline that hugs only the selected goal label. Keep “Tap to Set Goal” small and outlined, with no underline. Do not wrap or highlight the entire selected rail column.

**Why:** The user approved the inline selected-chip direction but found a full-column selection block visually larger than the Recovery rail itself.

**How to apply:** Preserve this treatment across Home and active-plunge Benefit Bars unless a future request explicitly changes the selected-goal visual language.
