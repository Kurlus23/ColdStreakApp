---
name: Benefit Bar visual direction
description: Approved compact visual treatment for the Benefit Bar goal selector and selected rail.
---

Use the Clean Rails layout with a small inline outline that hugs only the selected goal label. Keep the panel surface in the same dark navy family as the surrounding Home cards; benefit colors belong on labels, rails, and status accents rather than on a separate teal panel. Do not show a persistent “Tap to Set Goal” prompt above the rails. At rest, each benefit pane can open the goal picker, with Profile → Account as the alternate goal-setting location. Do not wrap or highlight the entire selected rail column.

**Why:** The user approved the inline selected-chip direction but found a full-column selection block and a top instructional prompt visually too large for the compact bar. Directly tappable panes preserve discoverability without adding vertical chrome.

**How to apply:** Preserve this treatment across Home and active-plunge Benefit Bars unless a future request explicitly changes the selected-goal visual language. Keep pane interaction disabled during an active plunge.
