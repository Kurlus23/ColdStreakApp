And here's why I like this architecture so much

The user is going to spend far more time looking at the normal plunge screen than playing trivia.

If you're doing a 5-minute plunge:

~4 minutes of normal plunge experience
~2 minutes total answering questions

So ColdStreak doesn't become:

"Trivia app with cold plunging."

It remains:

ColdStreak — with Brain Freeze built into the plunge experience.

That's an important distinction.

It also solves the UI problem completely

We don't need to cram:

Timer + temperature + heart rate + benefit bar + trivia + four buttons + streak + challenge + score

onto one screen.

We only need:

Normal mode

ColdStreak UI

Brain Freeze mode

Question + giant buttons

That's it.

And when the question disappears, the entire ColdStreak interface comes back exactly as it was.

One thing I'd change from the earlier concept

I'd probably make the question pop-up last closer to 10–15 seconds, but the 30-second cycle should remain fixed.

For example:

0:00 — plunge begins

0:30 — Brain Freeze question

0:40 — answer/result

0:40–1:00 — normal plunge

1:00 — next Brain Freeze

So the user gets approximately:

20 seconds ColdStreak → 10 seconds Brain Freeze → 20 seconds ColdStreak → 10 seconds Brain Freeze

And if they answer in 3 seconds?

Great. The popup closes early.

They get more time to enjoy the plunge.

That could actually make speed scoring feel even more meaningful:

Answer quickly → earn more points → get back to your plunge sooner.

So Brain Freeze isn't constantly demanding their attention.

It interrupts the plunge briefly, rewards them for thinking fast, and gets out of the way.
